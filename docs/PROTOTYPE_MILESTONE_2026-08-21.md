# Road Warrior Prototype Milestone: 2026-08-21

- Version: 0.1
- Status: Defined milestone
- Target date: 2026-08-21
- Definition date: 2026-08-01

## Purpose

This prototype is field research, not proof of success. Success is not required; useful evidence either way is the objective.

The prototype may be used to work on Road Warrior itself, creating a real-time feedback loop.

## Environment

- Android phone.
- 2025 Kia Niro EV.
- Android Auto navigation visible.
- Two-way voice through the car sound system.

## Operating Constraints

- One manual action before driving is acceptable.
- Once driving begins, the system should be hands-free.
- The user deliberately starts and ends the session.
- Navigation must remain usable.
- Replies must be clear through the car speakers.
- The conversation must be able to recover from temporary routing or connectivity problems.

## Minimum Loop

Think -> Talk -> Capture -> Distill -> Store -> Resume.

The user can use natural phrases such as:

- "Capture that."
- "Put that in the Horizon."
- "Remember that for later."
- "Bring me back to the main thread."

## Session Output

Each session output should include:

- Summary.
- Key discoveries.
- Decisions.
- Action items.
- Open questions.
- Horizon ideas.
- Open loops.

## Storage

The initial storage target is a Google Drive folder named `CarAI`.

## Required Pre-Trip Tests

- 10-minute drive.
- 30-minute drive.
- 60-minute drive.
