# Road Warrior Architectural Principles

- Version: 0.1
- Status: Frozen baseline
- Date: 2026-08-01

## Roles

- Front end: trusted thinking partnership.
- Back end: conductor.
- The relationship layer should express intent without knowing integration-specific mechanics.
- The conductor layer selects and coordinates capabilities.

## Capability Model

- Prefer integration over imitation.
- Prefer orchestration over duplication.
- Road Warrior should have few native capabilities.
- Specialized external systems should perform specialized work.
- Capability should be introduced when it creates value.
- Capability grows by invitation.
- Authority must lag behind trust.
- Understanding must deepen over time.
- Every new capability should feel like adding a musician to an orchestra, not rebuilding the concert hall.
